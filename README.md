# Lalith Alpuri — local AI systems

This repository publishes [lalithbuilds.github.io](https://lalithbuilds.github.io/), the interactive project home of Lalith Alpuri (@lalithbuilds). It maps the source and documentation for ALPURIS OS, EpisodAI, Episoda Core MCP, and the personal Ray/UWOF systems lab.

The public site is deliberately claim-aware: flagship repositories are linked to their source, while Ray/UWOF is described as personal local infrastructure based on the attached runner and model files. It is not presented as an independently verified hosted service.
