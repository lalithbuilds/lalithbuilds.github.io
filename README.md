# Lalith Alpuri — AI systems engineer & open-source developer

This repository publishes [lalithbuilds.github.io](https://lalithbuilds.github.io/), the official portfolio for **Lalith Alpuri** (also written **Alpuri Lalith**), an AI systems engineer and open-source developer publishing as [@lalithbuilds](https://github.com/lalithbuilds). Read the [canonical profile](https://lalithbuilds.github.io/about.html), [full résumé](https://lalithbuilds.github.io/resume.html), or explore the three projects: [EpisodAI](https://github.com/lalithbuilds/episodai), [Episoda Core MCP](https://github.com/lalithbuilds/episoda-core-mcp), and [ALPURIS OS](https://github.com/lalithbuilds/alpuris-os). The site also covers the personal Sentinel / UWOF lab and applied AI and simulation work at Ataraxia Pharma.

The portfolio uses plain HTML, CSS, and JavaScript. It has an animated 3D card composition, a scroll-held three-part thesis, an accessible project carousel, scroll-responsive transitions, and a motion control with reduced-motion support. The résumé is available as readable HTML plus PDF and DOCX downloads. There is no build step; run `python3 -m http.server` from this directory to preview it.

Project panels link to their public source. Scenario illustrations do not represent measured business outcomes. Ray/UWOF descriptions distinguish checkpoint and adapter files from runtime validation. The art direction takes inspiration from editorial, chapter-based sites while using original layouts, copy, and graphics.
