WHAT THE ORGANISM CONNECTSCHAPTER 03

TOOLS TO THINK.
TOOLS TO ACT.

01

Targeted web scout

toast1_fetch() searches Hacker News through Algolia and scrapes company-data pages for company queries. Retrieved text feeds the local generation path. It is a targeted connector, not a general web search engine.

02

Code-execution adapter

run_autonomous_agent() delegates to OpenInterpreter using an Ollama-hosted UWOF model. It enables automatic code execution; it is not a custom sandbox. The current UWOF Python environment cannot import OpenInterpreter because pkg_resources is missing, so the route needs repair before use.

03

Local inference tiers

The MLX route pairs the UWOF 7B checkpoint with a Toast 1.5B draft model; a separate 135M path handles short reflex responses. All three model directories are present locally. The runner selects these paths with explicit keyword rules, so availability of files and successful end-to-end execution are distinct claims.
