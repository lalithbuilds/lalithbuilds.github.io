BUILT-IN TOOLS / UWOF ORGANISMCHAPTER 03

TOOLS TO THINK.
TOOLS TO ACT.

01

Built-in web research

The organism includes a web-search tool for targeted research. toast1_fetch() searches Hacker News through Algolia and retrieves company information for research prompts, then passes useful source text into the local answer workflow.

02

Built-in code interpreter

run_autonomous_agent() routes coding tasks to OpenInterpreter with an Ollama-hosted UWOF model. The integrated execution path lets the agent write and run code as part of its workflow.

03

Working local model tiers

The active MLX inference stack routes work across the UWOF 7B model, Toast 1.5B draft model and a 135M reflex model. Keyword-based routing selects the tier suited to each request, keeping generation on the local Apple Silicon setup.
