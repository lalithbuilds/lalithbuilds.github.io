How the projects fit together

ALPURIS OS explores coordinated agent behavior in a simulated world. EpisodAI provides a richer local memory engine. Episoda Core MCP offers a simpler memory option when minimal dependencies matter. Each repository documents its own setup, limits, tests, and source code.

Common questions

Who is Lalith Alpuri?

Lalith Alpuri, also written Alpuri Lalith, is the developer behind @lalithbuilds and the three open-source projects linked above. The GitHub profile and project repositories are the source for current code and documentation.

Are EpisodAI and Episoda Core MCP the same project?

No. EpisodAI is the richer local agent-memory engine with hybrid retrieval and Obsidian workflows. Episoda Core MCP is a smaller Python standard-library and SQLite memory server. ALPURIS OS is a separate multi-agent city simulation.
